# 🛒 Blinkit Grocery Data Analysis | SQL + Python + Power BI

### 📌 Project Overview
End-to-end data analysis project on Blinkit grocery sales data. Performed data cleaning & EDA in **Python (Pandas)**, business querying in **SQL**, and built an interactive dashboard in **Power BI** to deliver actionable business insights.

### 🎯 Workflow
**1. Python (Pandas) - Data Cleaning & EDA**
- Handled missing values & inconsistent fat content labels
- Converted data types, created new calculated columns
- Exploratory analysis: Sales distribution, Item type analysis, Outlier detection

**2. SQL - Business Analysis**
- Used GROUP BY, JOIN, Sub Queries , WINDOW functions to answer business questions
- Queries: Total sales by outlet, Top 5 selling products, Year-wise growth %

**3. Power BI - Visualization**
- Built 2-page interactive dashboard with slicers & KPIs
- DAX measures for Total Sales, Average Rating

### 📊 Key Insights
- Total Sales: $1.20M | Avg Rating: 3.92
- Low Fat products = 64.7% of sales (776K)
- Tier 3 location & Medium outlet size = Highest performance
- Sales peaked in 2018, Meat category has highest rating (3.98)

### 🛠️ Tech Stack
- Python: Pandas, NumPy, Matplotlib
- SQL: MySQL
- Power BI: DAX, Power Query
- Tools: Excel, GitHub
